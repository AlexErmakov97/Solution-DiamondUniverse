# Архитектурное видение

## Задача

Концептуально задача состоит в том чтобы подстроить бизнес под текущие реалии, в которых физическое присутствие сильно
затруднено. Для этого необходимо обеспечить качественную оценку камней и безопасную логистику.
Переход в онлайн поможет Diamond Universe не снижать темпы своего основного технологического процесса, а так же за счет
перехода привлечь больше потребителей желающих преобрести камни, а покупателям не понадобится лично присутствовать при
оценке и покупке.
Важность этого решения обуславливается экономичсекой соствляющей, которая подтверждается цифрами: продажи необработанных
алмазов упали примерно на треть, а поставки алмазов на огранку — почти наполовину.

## Контекст

Задача возникла именно сейчас из-за обстоятельств непреодалимой силы в лице пандемии.
Сейчас основной процесс происходит оффлайн и он полностью отлажен, целевое решение предпологает использовать новую схему
взаимодейтсвия.

**Текущее состояние**:

- ИС «Алмазы» планирование работ, присвоение идентификаторов и подготовка ведомостей
- ИС «Аукцион» проведение аукциона (оффлайн)
- ИС «Бухгалтерия» ведение контрактов, актирование и оплата услуг компаний-перевозчиков
- ИС «Логистика» перевозка алмазов покупателю по стране и за границу

**Целевое состояние**:

- ИС «Лаборатория» (подрядчик): оцифровка алмазов
- ИС «Алмазы»: отбор алмазов для цифрового аукциона (новый), планирование работ, присвоение идентификаторов и подготовка
  ведомостей.
- ИС «Логистика»: отправка алмазов в лабораторию и возврат в офис после оцифровки (новый), перевозка алмазов покупателю.
- ИС «Аукцион»: публикация данных для клиентов (новый), проведение аукциона.
- ИС «Бухгалтерия»: актирование и оплата услуг лаборатории (новый), компаний-перевозчиков, ведение контрактов.

**Ограничения**:

- сжатые сроки (2 месяца) для реализации промежуточного решения
- промежуточное решение не должно затрагивать в плане доработок текущие ИС
- внешний подрядчик ИС «Лаборатория» должен обеспечить качество оцифровки
- конфиденциальность данных о камнях и участниках аукционов
- поиск специалиствов для целевой реализации автоматизации процессов из этой предметной области + переобучение текущих
  сотрудников вести дела онлайн

## Оптимальное решение

Два этапа: промежуточное решение (Excel, существующие ИС, частное облако) и целевое (автоматизация, интеграции, перенос
сервисов на свои серверы).

- Этапы. Подготовка промежуточного решения, первый аукцион, Fit-Gap анализ, проектирование целевого решения, реализация,
  переход.
- Команда. см. Участники проекта и их задачи
- Сроки: 2 месяца на промежуточное решение, 1 год на реализацию и переход

**Пилотные торги (промежуточное решение)**. Покупатели заранее изучают описания камней в частном облаке. Во время торгов
Покупатели подключаются по видеосвязи и делают
ставки голосом или в чате. Аукционист (менеджер) ведёт торги, вносит ставки удалённых участников в ИС «Аукцион» и
фиксирует победителя. Ссылки на данные лота в облаке вносятся в существующее текстовое поле описания лота; если такого
поля нет, связь лота со ссылкой ведётся в реестре результатов оцифровки по ID камня. Итоги торгов (данные победителя, ID
купленного камня, цена, адрес доставки) менеджер переносит в реестр победителей, по нему логист оформляет отгрузку в ИС
«Логистика», а менеджер по отбору ставит камню статус «продан» в ИС «Алмазы». В целевом решении эти обмены
автоматизируются.

| Участник                                  | Задачи                                                                                                                                                          |

| Архитектор                                | архитектура промежуточного и целевого решений, согласование интеграций и форматов обмена                                                                        |
| Аналитики                                 | описание процессов, шаблоны Excel-реестров, требования к доработкам ИС                                                                                          |
| Эксперты-оценщики                         | вместе с покупателями согласуют состав цифрового описания камня и критерии его достаточности для удалённой оценки; приёмка качества оцифровки по этим критериям |
| Ключевые покупатели                       | участвуют в согласовании состава описания, проверяют пробные карточки камней, дают обратную связь после пилотных торгов                                         |
| Представитель «Лаборатории»               | оцифровка по согласованному составу описания, выгрузка результатов по шаблону с ID камня, акты выполненных работ                                                |
| Менеджер аукциона и аукционист            | подготовка лотов, регистрация и допуск покупателей, проведение торгов по видеосвязи, ввод ставок, ведение реестра победителей                                   |
| Переводчик / редактор                     | описания камней и условия торгов на английском языке, единый словарь терминов                                                                                   |
| Логисты и служба безопасности             | перевозка в лабораторию и обратно, отгрузка победителям по реестру победителей                                                                                  |
| Бухгалтерия                               | договоры, актирование и оплата услуг лаборатории                                                                                                                |
| Специалисты ИБ                            | требования к облаку, сервису видеосвязи и каналам передачи данных                                                                                               |
| Облачный провайдер                        | размещение данных, разграничение доступа покупателей                                                                                                            |
| Разработчики                              | доработки ИС и интеграции в целевом решении                                                                                                                     |

**Показатели оценки пилота** (сравниваются с последними офлайн-аукционами):

| Показатель                | Как считается                                                                                                                                  |
|:--------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------|
| Доля проданных лотов      | проданные лоты / выставленные лоты                                                                                                             |
| Стоимость подготовки лота | затраты на оцифровку, перевозку в лабораторию, облако и работу сотрудников / число лотов, в сравнении со стоимостью подготовки офлайн-аукциона |
| Цена продажи              | средняя цена продажи к стартовой цене и к цене аналогичных камней на офлайн-аукционах                                                          |
| Участие покупателей       | число зарегистрированных покупателей и доля сделавших хотя бы одну ставку                                                                      |
| Достаточность описания    | доля лотов, по которым покупатели запрашивали дополнительную информацию, и число претензий после доставки                                      |
| Срок подготовки           | время от отбора камней до проведения торгов                                                                                                    |
