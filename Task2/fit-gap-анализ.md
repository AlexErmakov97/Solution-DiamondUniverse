# Fit/Gap-анализ

## Список систем

| ИС                 | Признак                       | Существующая функциональность                                               | Новая функциональность                                                | Комментарий                                                                                                                                                                                                                                |
|:-------------------|:------------------------------|:----------------------------------------------------------------------------|:----------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Алмазы             | существующая                  | планирование работ, присвоение идентификаторов<br/> и подготовка ведомостей | отбор алмазов для цифрового аукциона                                  | - ведомости для передачи камней в лабораторию<br/>- категоризация камней (по признаку готовности для передачи на аукцион)<br/>- планирование и отслеживание работ по оцифровке<br/>- связь камня с цифровым представлением                 |
| Аукцион            | существующая                  | проведение аукциона (оффлайн)                                               | публикация данных о камнях для клиентов, проведение аукциона (онлайн) | - регистрация покупателей для участия в онлайн аукционе<br/>- загрузка и хранение цифрового описания камней<br/>- отображение лотов<br/>- онлайн ставки<br/>- регистрация покупки<br/>- обеспечение сохранности данных покупателей и лотов |
| Бухгалтерия        | существующая                  | ведение контрактов, актирование и оплата услуг компаний-перевозчиков        | актирование и оплата услуг лаборатории                                | - добавление нового вида счет-фактуры для Лаборатории                                                                                                                                                                                      |
| Логистика          | существующая                  | перевозка алмазов покупателю по стране и за границу                         | отправка алмазов в лабораторию и возврат в офис после оцифровки       | - обеспечение безопасного маршрута из офиса в лабораторию и обратно                                                                                                                                                                        |
| Лаборатория        | новая                         | -                                                                           | оцифровка алмазов                                                     | - оцифровка (в соответсвии с требованиями экспертов), защищенная передача результатов                                                                                                                                                      |
| Облачный провайдер | новая (промежуточное решение) | -                                                                           | хранение и публикация данных оцифровки для покупателей                | - требования к провайдеру: доступность, защита данных                                                                                                                                                                                      |

## Списов интеграций

| Интеграция                          | Признак      | Подход промежуточный | Подход целевой | Данные                                                                      |
|:------------------------------------|:-------------|:---------------------|:---------------|:----------------------------------------------------------------------------|
| ИС «Алмазы» → ИС «Логистика»        | существующая | автоматически        | автоматически  | существующие + новые (документы о перевозке камней в лабораторию и обратно) |
| ИС «Логистика» → ИС «Бухгалтерия»   | существующая | автоматически        | автоматически  | существующие (данные оплаты услуг перевозчика)                              |
| ИС «Алмазы» → ИС «Лаборатория»      | новая        | вручную              | автоматически  | новые (идентификаторы камней, документы передачи)                           |
| ИС «Лаборатория» → ИС «Аукцион»     | новая        | вручную              | автоматически  | новые (документы с описанием камней)                                        |
| ИС «Лаборатория» → ИС «Бухгалтерия» | новая        | вручную              | автоматически  | новые (новая счет-фактура)                                                  |
| ИС «Алмазы» → ИС «Аукцион»          | новая        | вручную              | автоматически  | новые (состав лотов и ID камней)                                            |
